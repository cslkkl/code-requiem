# .agents/notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

## 本目录特有约束

- 每篇笔记第 3 行必须是状态行：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`
- 决策类必须含 `## 替代方案（强制）`——不记录「试过什么、为什么不行」，下次必被重诉
- 命名：决策类 `YYYY-MM-DD-<主题>`；依据类可省日期
- 归档形态是就地标记，**不建 `archived/` 子目录**
- 不建索引文件，不逐篇列清单（去哪查看 [README.md](README.md)）
