# .agents/notes/ — 决策与依据记录

## 两类记录

| 类型 | 触发源 | 判据 | 命名 |
|---|---|---|---|
| 决策 | 做选择 | 在几个方案里挑一个 | `YYYY-MM-DD-<主题>` |
| 依据 | 做调查 | 看事实、对照、得出结论 | 可省日期 |

## 去哪查

- 想看「为什么这么定」→ 读本目录下的笔记，状态行为 `生效` 的就是当前有效的决定
- 想看「系统现在是什么样」→ [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)
- 想看「这个模块有什么、改哪」→ 各源码目录的手册
- 想看「下一步做什么」→ 根 [AGENTS.md](../../AGENTS.md) 的待办
